## 恢复与证据边界

- 单卡恢复逐项核验 65 项模型状态、91 项优化器槽、61 个 FP32 主权重别名、调度器、采样游标和实际下一批。1000 步的 2000 微批、8000 项输入字段与原始 MF ledger 对应。
- HP2500 原生 checkpoint 独立 CPU 读回，65 项模型、91 项槽、734 项优化器 metadata、521 项 static leaf 与最终 live 记录对应，张量均有限。采样游标为 5000。已保存的 Torch CPU/device、Python RNG 与 live 一致。stock checkpoint 没有保存 NumPy RNG，主进程 6000 个已观测快照摘要一致。该观测仅限主进程全局 RNG 和所记录边界，live 摘要单独保留。
- 四卡原生 DCP 及重分片恢复核验 624 项四 rank 模型/槽摘要，逐步 LR 一致。CP 的全量/切片摘要不可直接相等比较，证据结合数据采集器逐字段真实内容检查、连续分片覆盖和 TP 副本摘要核对。
- HP 更新 LR 由恢复 LR 和前一调度器输出按已核实的调用时序推导；MF LR 在优化器更新时实际记录。两端日程参数及 step 索引一致，浮点 cosine 求值产生微小差异。1000 步中映射到 FP32 后 645 步一致、355 步不同，最大原值绝对差 4.975399236e-12，相对差 1.247339859e-7。该诊断没有额外验收阈值。
- NPU 46 项模块探针旧/新对应张量逐位相等，覆盖非对称 mHC 各自的 reference/fused 路径、MLA 与 router。reference/fused 之间仍有实测浮点差异。Muon 逻辑分组继续经框架回调执行，本轮模型没有新增固定规约轨迹。
- 单卡与四卡运行重叠，本轮数据用于数值回归。端到端性能与显存收益需要独立受控测量。
