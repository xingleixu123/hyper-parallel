# Xing4.0 单卡训练精度对比（1501–2500）

MF 连续训练至 step 2500，HP 从 MF step 1500 恢复并续训至 2500；以下比较同一窗口的 1000 个更新，差值均为 HP − MF。实验为 129 B231 单卡、官方 Xing4.0 适配、2 Dense + 1 MoE 主干和 1 MTP、GBS 2 / LBS 1、序列长度 4096，沿用原学习率日程。MF 使用 MindSpore 2.10.0，HP 使用 PTA 2.12，CANN 9.2 为本次实验组合，不宣称官方配套。模型源码采用 MF `52f614e`、HP `c99f410` 组合树及相关共享依赖。

| 指标 | 有符号均值 | abs(mean) | 正 / 负 / 零 | MAE | 最大绝对差（step） |
| --- | ---: | ---: | ---: | ---: | ---: |
| LOSS | -0.000041772604 | 0.000041772604 | 475 / 525 / 0 | 0.000614553452 | 0.004079818726（2471） |
| 未缩放 MTPLOSS | -0.000181610495 | 0.000181610495 | 469 / 531 / 0 | 0.001242742091 | 0.009748399258（2200） |

两个指标的 `abs(mean(HP − MF)) ≤ 0.005` 均满足完整窗口判据；该阈值约束均值，不是逐步最大误差。输入四字段 8000/8000 及指定 RNG 摘要 12000/12000 一致，比较覆盖范围分别为 HP 的前向与反向、MF 的前向；该结果不外推全部随机算子、多卡或其他配置。
