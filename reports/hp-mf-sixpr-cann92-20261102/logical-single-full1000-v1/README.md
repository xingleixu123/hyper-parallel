1000步×2 micro×4字段共8000项输入的shape、dtype和摘要一致；首个恢复后的实际batch也与MF原生记录一致。学习率、步号、采样进度和记录的RNG域经逐步核对；这不等价于所有随机算子或所有执行路径相同。

MF参考运行已记录1–2500步，但原runner在终态将IPC映射误识别为库并以exit 1结束；条件性witness不能补证终态inode/权限连续性。HP起点的既有native1500检查点已有独立CPU全局读回；本次终点2500的extra state已独立CPU读回，终点全局模型和optimizer tensor的独立读回尚未进行。

本次MF采用的构造链为常数五次NS系数，HP记录为asym5；两侧还存在规范化和LR/shape缩放次序差异。它们是需要受控实验的数学差异，现有loss不确定哪一项造成偏移。本包不宣称四卡通过；正式四卡验收尚未完成。
