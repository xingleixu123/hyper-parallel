**What does this PR do / why do we need it**:

通用重算发现器原本只识别解码器序列，漏掉独立的Hugging Face `GradientCheckpointingLayer`。JT的`mtp.layers.0.transformer_layer`不在主干decoder序列，因此full未覆盖完整MTP block。修复目标是实际重放覆盖；loss相同本身不能证明覆盖正确。

本修改补充发现独立解码块，选中外层边界后排除已覆盖子节点；识别时解开支持的HyperParallel/PyTorch wrapper，重复应用保持幂等。JT禁用继承的HF重算回退路径，统一使用HyperParallel非重入重算及辅助状态重放上下文。直接调用HF的`gradient_checkpointing_enable()`被拒绝，因为该回退不满足JT状态契约；对外full/selective名称不变。

当前唯一提交为`00ae8a77b36ed4a306147255781d986638249057`。CPU回归使用可恢复的默认设备fixture，避免已导入TorchNPU时CPU checkpoint意外初始化NPU；异常也恢复原状态，生产设备推断未改。
