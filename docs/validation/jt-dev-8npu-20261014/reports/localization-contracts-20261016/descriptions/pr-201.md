**What does this PR do / why do we need it**:

Muon 原先固定把 Newton–Schulz 的输入和更新通信缓冲转为 BF16。配置 FP32 主参数或 FSDP FP32 梯度归约并不会改变这一点，因此无法选择完整 FP32 正交化路径，也不能通过 checkpoint 明确保持这一数值配方。

增加 `ns_dtype="bfloat16" | "float32"` 参数组配置，默认保持历史 BF16 行为。选择涵盖 momentum 阶段输出、内置 NS 计算及更新 relay 缓冲，包含无梯度 rank 和空分片；batch 软上限按元素字节数计费。自定义 momentum 回调的返回值转为独立存储，防止 NS 原地操作别名修改仍有效的梯度或状态。自定义 NS 回调仍自行负责内部数学精度。

该值随 optimizer 参数组持久化；旧 checkpoint 缺少字段时恢复历史 BF16，而不是继承新构造器的 FP32 默认。Trainer 为 DCP 提供兼容的加载模板，覆盖 chained optimizer、MixedPrecisionOptimizer、平铺及嵌套参数组。仅恢复权重时保留新 optimizer 配置。加载前检查全部 optimizer 叶子，避免后面的非法 Muon 配置导致前面的 AdamW 已被部分写入。

不改变主参数或 momentum 存储类型、NS 系数、轮数、epsilon、学习率及后端 HF32 设置。新增示例说明解释精度、性能和恢复语义。
