**What does this PR do / why do we need it**:

恢复训练原先会恢复 optimizer step 和数据位置，却让环境 meter 保持刚初始化的状态。保存 step200 后恢复，step201 的累计样本数是 8，而独立连续参考为 1608；累计监督 token 是 6304，而参考为 3720095。模型训练与逐步计数本身正确，累计进度上报从零重启。

本修改将已有 meter 的 state_dict 保存到 checkpoint extra state，并随训练状态恢复。该字段可选，兼容没有 meter 的 Trainer 和旧 checkpoint；仅恢复权重时不加载历史 meter。优化器、梯度、loss 系数、数据位置和 RNG 行为保持原契约。

旧 checkpoint 没有保存历史计数时仍可加载，但不能凭 step 数猜测累计 token，因为各批有效 token 数并不固定。没有新增公共配置，不涉及官网页面修改。
