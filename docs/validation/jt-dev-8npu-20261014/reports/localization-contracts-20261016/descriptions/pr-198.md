**What does this PR do / why do we need it**:

FSDP 已克隆分片参数并替换模块别名，但 scheduler/state 仍通过 `source_shard_infos` 的字典键和显式复制参数集合持有原始完整 Parameter；这些源参数此前已搬到设备，EP/CP 训练因而持续保留整份初始化存储。

本修改在 state 构造完成后释放 scheduler 的初始化容器，在 HSDPParam 构造完成后释放 state 的源映射和独立复制的 replicate 集合。活跃 HSDPParam 保留已消费的元数据；调用者容器不被清空，忽略参数继续存活，共享参数别名保持正确，原始 storage 不做原地 resize。没有公共 API 或官网页面变化。
