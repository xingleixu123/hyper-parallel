# FP32 Linear 输入梯度候选：已有长前缀否决及存储清理

## 结论和边界

**当前候选不能解决主 LM loss 的 0.005 对齐要求。** CP2 第二轮完整跑完 200 步，匹配的新 FSDP8 参考因其他任务出现而在 163 步后让卡；只比较双方实际拥有的 1–163 步、全部 8 rank。主 LM loss 最大绝对差为 **0.0120849609375（第 151 步）**，第 **112 步**首次超过 0.005。原生输入梯度配方在相同 1–163 步窗口的最大差为 0.011061668395996094。此前三步改善没有延续为长前缀通过。

本结果足以否决该候选在当前配方下满足整个 200 步门槛的假设，**不是完整 200 步配对验收**。未拼接不同轮次的前缀，未修改严格比较器或降低门槛。FSDP 缺失的 164–200 步仍然缺失；不把成功完成的 CP2 或自比较零误差当成跨布局通过。主 LM loss 已独立失败，MTP/aux 仅保留观测，不作为当前额外优化目标。

## 执行和身份核验

三轮均在 129、固定镜像 `sha256:5f9e677f439d11ab4e7c888f54b142335a27eee7411cbd2ce894a4798a70146d`、集成训练源 `18602c4524dc664b81b2bad9a7b624455ce1494f` 下执行；JT_dev 基点 `f637ef7ee4d4b416800716f1ebaaae7709b8a06a` 包含 #180/#186，CANN 为 9.2.0-beta.2。未改变 LR、loss 权重、数据、全局 batch 或初始化。

| 实验 | 每 rank 实际步数 | 容器占用秒数 | 退出与释放 |
|---|---:|---:|---|
| `r129-f637-dgrad-fsdp8-fp32-200-v1` | 163 | 401.573 | 其他任务出现，停止自有容器；137，已释放 |
| `r129-f637-dgrad-cp2-fp32-200-v1` | 0 | 67.153 | 初始化期间其他任务出现，停止自有容器；137，已释放 |
| `r129-f637-dgrad-cp2-fp32-200-v2` | 200 | 550.382 | 0，完成标记齐全，已释放 |

以上是生命周期占用时间，不是生产步时。每次释放后满足全局至少 1200 秒间隔，启动再次检查空卡；外部任务未被停止。一次 CP2 v2 启动检查只有 7 张空卡，守卫拒绝预留，之后才在 8 张空卡时启动。v2 仅更换实验输出目录和独立端口，四份数值 helper 与 v1 逐字节相同。

候选保持 BF16 Linear 前向、FP32 输入梯度后转回 BF16，权重梯度通过原生 BF16 路径重放。它有额外重放成本，不能作为生产性能改善证据。CP2 实际记录 76,800 次 FP32 输入梯度调用；FSDP 记录 31,296 次。两组各自前三步与此前同配方 C/D 短臂的各 loss 和梯度范数差为 0；初始化及输入身份均通过。候选并非全模型 FP32。

未修改的严格比较器仍返回 FAIL，保留 28 条精确预期的完整性问题（中断参考的退出/完成标记与窗口不足等），没有额外输入、初始化或其他完整性不一致。离线前缀分析只单独报告该已验证窗口；没有把严格比较器的失败改为通过。检视为主代理自审及独立执行的离线复算，不冒称另有独立审阅者。
