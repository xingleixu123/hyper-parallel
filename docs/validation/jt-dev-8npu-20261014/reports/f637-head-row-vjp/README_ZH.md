# 真实 LM head 的局部反向：固定操作数，改变行形状

**已确认一处局部行形状效应，尚未证明它是200步训练漂移的完整根因。** 同一组真实输入、权重和上游梯度，原生反向拆成2048行时产生少量差异；补零恢复4096行后，全部局部输入梯度重新相等。观察器未替换实际训练梯度，3步×8rank所有loss及梯度范数对原FSDP参考均差0。

![局部反向的行形状对照](../../figures/f637-head-row-vjp-zh.png)

## 对照设计与原始结果

实验`r129-f637-head-row-vjp-fsdp8-3-v1`仅观察rank0首步第一个主LM head调用。真实输入`[1,4096,5120]`、完整权重`[152064,5120]`、上游梯度`[1,4096,152064]`，均为BF16。私有副本在FSDP的前向后分片恢复之前获取，独立autograd重放后立即释放；返回原训练图的梯度不作替换。

| 相对全4096行的原生反向 | 完整比较坐标数 | 不同坐标数 | 最大绝对差 |
| --- | ---: | ---: | ---: |
| 相同形状重复一次 | 20,971,520 | 0 | 0 |
| 按两半2048行分别计算 | 20,971,520 | 2,029 | 1.1920928955078125e-7 |
| 按128行小块计算 | 20,971,520 | 1,546 | 1.1920928955078125e-7 |
| 两半分别补零回4096行，再取原行 | 20,971,520 | 0 | 0 |

这排除了“本次局部差异只是双方输入不同”这一解释：每种局部重放都使用同一次真实调用的固定操作数，且操作数版本计数未变化。重复对照为0；补回原行数的对照也为0，支持行形状参与该数值差异。但不能从中推断具体CANN算法选择或累加次序，也不能将本实验的零填充输入等同于实际CP的完整前向输入。

另对8行×8列的64个坐标使用CPU FP64沿完整词表维度求和，**将结果转回BF16后**与原生全行结果逐坐标相等。该oracle是有限采样，不能声称全部梯度与数学精确值相等。

原始张量摘要、所有统计与训练对照见[完整审计JSON](f637-head-row-vjp-fsdp8-3-v1-audit.json)；[图像来源SHA](f637-head-row-vjp-figure-manifest.json)和[实际执行计划](f637-head-row-vjp-plan.md)随附。
