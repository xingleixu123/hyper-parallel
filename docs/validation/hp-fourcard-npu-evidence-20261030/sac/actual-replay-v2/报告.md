# SAC replay v2：单卡 NPU 证据核对

成功的单卡合成模块前后向中，修复前后 SAC 下方的 attention forward overload 重算派发从 1 次变为 0 次；两投影 GMM 链的重算派发从 2 次变为 1 次。原始事件逐条重算与结果 JSON 一致，两个策略均恢复 phase 至 `outside`，且 `allow_cache_entry_mutation=False`。

| 阶段 / overload | 原策略 | 修复策略 |
|---|---:|---:|
| attention forward | 1 | 1 |
| attention recompute | 1 | 0 |
| attention 普通 backward grad | 1 | 1 |
| GMM forward | 2 | 2 |
| GMM recompute | 2 | 1 |
| GMM 普通 backward | 4 | 4 |
| SwiGLU forward / recompute / backward | 1 / 1 / 1 | 1 / 1 / 1 |

两策略所有记录的 output、梯度和 attention max_logits 均有限。两模块的输入 shape、dtype、SHA 均与 v3 数值诊断一致，每条件 clone SHA 核验记录为通过。v3 中 GMM 与无 checkpoint 基线逐位一致；attention 的无 checkpoint 基线梯度自身有波动，严格逐位结论仍为 **inconclusive**。

client 与 worker 均 exit 0；entry 记录 `ASCEND_RT_VISIBLE_DEVICES=0`、设备数 1，设备映射包含物理 davinci0 与必要管理节点；11 个 gate/runtime 快照的 PID、starttick、namespace 及 raw mapping 均匹配。采样快照不能证明整个窗口连续独占。运行后 2661 文件源树核验记录通过。此前 replay 首次 busy guard 和 idle retry 的 mapping guard 失败证据均保留；后者缺原始 mapping，不能据此认定外部进程占卡。

这些是 **below-SAC dispatch 次数**，不是 CANN kernel 次数；实验没有性能计时，也不能证明完整模型、optimizer 或训练正确性。原始 tensor 未保存在小 JSON 中，有限性和逐位结果核对的是已保存的记录。机器结果见本目录 result.json；完整审计输入及核验脚本留在原始归档。未运行额外 NPU 作业。
