运行记录为物理卡 0、可见设备数 1、worker exit 0；合成 BF16 输入不是训练 batch，未覆盖完整模型、router、optimizer 或训练验收。输入 clone 的 SHA 检查记录为通过；源树运行后核对 2661 文件。保留 v1 设备初始化失败和 v2 内存预检失败证据。v3 的 sleep 容器记录为保留，不对它做操作。
